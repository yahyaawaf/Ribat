# موقع جمعية رباط للتنمية الأسرية بالطوال

موقع عربي RTL جاهز للرفع على GitHub Pages، دون أي عملية بناء أو مكتبات خارجية.

## ما يتضمنه الموقع
- الصفحة الرئيسية مع عداد إطلاق بتاريخ **29 أكتوبر 2026م** (شهر بعد تاريخ إعداد الموقع).
- تسجيل المستفيدين.
- الخدمات والبرامج والأخبار.
- التطوع والشراكات.
- التواصل والخصوصية.
- تصميم متجاوب للجوال والكمبيوتر.
- أدوات تسهيل الوصول: تكبير/تصغير النص، تباين عالٍ، تقليل الحركة.
- شعار الجمعية من الملف المرفق، بعد تحسين حجمه للاستخدام على الويب.
- PWA/Service Worker لدعم تجربة أسرع.

## أهم ملف للتعديل
`assets/js/config.js`

يمكن منه تعديل:
- تاريخ الإطلاق `launchDate`
- الهاتف والبريد وروابط التواصل
- رابط استقبال النماذج `forms.endpoint`

## تفعيل تسجيل المستفيدين فعليًا
الموقع ثابت، لذلك **لا يجب حفظ بيانات المستفيدين داخل GitHub**. تم تضمين مثال آمن نسبيًا وسهل باستخدام Google Apps Script:
1. أنشئ Google Sheet خاصًا بالجمعية واجعل الوصول إليه للمخولين فقط.
2. افتح: Extensions > Apps Script.
3. انسخ محتوى `backend/google-apps-script/Code.gs`.
4. Deploy > New deployment > Web app.
5. انسخ رابط Web App وضعه في `assets/js/config.js` داخل `forms.endpoint`.
6. اختبر كل نموذج قبل نشر الرابط للعامة.

> يفضّل إضافة حماية إضافية من الرسائل المزعجة وسياسة احتفاظ بالبيانات قبل التشغيل العام.

## رفع الموقع على GitHub Pages
1. أنشئ Repository جديدًا.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع.
3. من Settings > Pages اختر Deploy from a branch.
4. اختر الفرع `main` والمجلد `/ (root)`.
5. احفظ وانتظر رابط GitHub Pages.

## قبل الإطلاق الرسمي
- أضف الهاتف والبريد ووسائل التواصل الرسمية فقط.
- استبدل نصوص الرؤية والرسالة بالقيم المعتمدة رسميًا.
- أضف الأخبار والبرامج المعتمدة فقط.
- اختبر إرسال النماذج وسياسة الخصوصية.
- لا تضع بيانات مستفيدين أو ملفات سرية داخل مستودع GitHub.
