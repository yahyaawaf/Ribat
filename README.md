# موقع جمعية رباط للتنمية الأسرية بالطوال — نسخة الإدارة

موقع عربي RTL جاهز للرفع على GitHub Pages، مع لوحة إدارة ومحتوى ديناميكي عبر Google Apps Script.

## التحديثات في هذه النسخة
- توحيد خط الموقع بهوية عربية قريبة من أسلوب كتابة الشعار باستخدام **El Messiri** عبر Google Fonts، مع بدائل عربية عند عدم توفر الاتصال.
- إضافة `admin.html` كلوحة إدارة كاملة للمحتوى.
- إدارة: الإعدادات العامة، الصفحة الرئيسية، عن الجمعية، أوصاف الصفحات، الخدمات، البرامج، الأخبار، بيانات التواصل، وتاريخ الإطلاق.
- إدارة المستفيدين والطلبات: عرض، بحث، تصفية، تحديث الحالة، حذف، وتصدير CSV.
- إضافة نافذة منبثقة للعد التنازلي للإطلاق الرسمي، وتختفي تلقائيًا بعد **30 ثانية** افتراضيًا، ويمكن تعديل المدة من لوحة الإدارة.
- إضافة مصادقة خادمية للوحة الإدارة عند ربط Google Apps Script.

## تجربة لوحة الإدارة محليًا
افتح `admin.html`.

بيانات المعاينة الافتراضية:
- اسم المستخدم: `admin`
- كلمة المرور: `Ribat@2026!`

> هذه البيانات مخصصة للمعاينة المحلية فقط. عند نشر الموقع للعامة، فعّل Google Apps Script واتبع خطوات الأمان أدناه. لوحة GitHub Pages وحدها لا يمكن أن توفر حماية حقيقية بكلمة مرور لأنها موقع ثابت.

## تفعيل الإدارة الآمنة واستقبال النماذج
1. أنشئ Google Sheet خاصًا بالجمعية، ولا تشاركه للعامة.
2. افتح **Extensions > Apps Script**.
3. انسخ محتوى `backend/google-apps-script/Code.gs`.
4. من محرر Apps Script شغّل الدالة `setupRibatAdmin()` مرة واحدة.
5. افتح **Execution log** وانسخ اسم المستخدم وكلمة المرور المولدين، واحفظهما في مكان آمن.
6. اختر **Deploy > New deployment > Web app**.
7. Execute as: **Me**، والوصول: **Anyone** (بحسب سياسة الجهة).
8. انسخ رابط Web App وضعه في `assets/js/config.js` داخل `forms.endpoint`.
9. ارفع ملفات الموقع إلى GitHub Pages، ثم افتح `admin.html` وسجّل الدخول بالحساب المولد.
10. غيّر اسم المستخدم وكلمة المرور من قسم **الأمان والدخول** بعد أول دخول.

## ملاحظات أمنية مهمة
- بيانات دخول الإدارة الحقيقية لا توجد داخل ملفات GitHub؛ يتم حفظها في **Script Properties** داخل Google Apps Script.
- جلسة الإدارة تنتهي تلقائيًا بعد 6 ساعات.
- لا تضع بيانات المستفيدين داخل مستودع GitHub.
- اختبر الصلاحيات والنماذج قبل نشر رابط الموقع للعامة.
- إذا كان مستودع GitHub عامًا، فلا تضع فيه أي كلمة مرور أو مفتاح API أو بيانات سرية.

## التحكم بالعد التنازلي
من `admin.html` > **الإعدادات العامة** يمكنك تعديل:
- تاريخ ووقت الإطلاق.
- عنوان العد التنازلي.
- النص أسفل العداد.
- مدة ظهور النافذة (الافتراضي 30 ثانية).
- تشغيل/إيقاف النافذة.
- إظهارها مرة واحدة في الجلسة أو مع كل تحميل.

## رفع الموقع على GitHub Pages
1. أنشئ Repository جديدًا.
2. ارفع محتويات هذا المجلد إلى جذر المستودع.
3. من **Settings > Pages** اختر **Deploy from a branch**.
4. اختر `main` والمجلد `/ (root)`.
5. بعد النشر افتح الصفحة الرئيسية و`admin.html` واختبرهما من الجوال والكمبيوتر.
